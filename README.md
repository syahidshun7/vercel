# Portfolio Vercel Ready

Website portfolio statis yang bisa langsung di-deploy ke Vercel.

## Deploy
1. Upload isi folder ini ke repository GitHub.
2. Import repository tersebut di Vercel.
3. Framework Preset: Other.
4. Tidak perlu Build Command.
5. Deploy.

Sebelum deploy, ganti email `hello@example.com` dan link project di `index.html`.
